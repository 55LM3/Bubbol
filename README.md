# Bubbol

Bubbol! is a free, open-source multiplayer sandbox! 🫧


## installation


FOR WINDOWS:

1. Download the latest .exe release from the releases tab
2. Run Bubbol.exe
3. You're done!


FOR LINUX:

1. Download the latest .zip release from the releases tab
2. Run Bubbol.zip
3. You're done!
